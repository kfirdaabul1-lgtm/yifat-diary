# היומן של יפעת: מדריך העלאה לאינטרנט

יומן לעורכת דין: מסך יומי, עמוד שבועי בסגנון יומן נייר, מועדי הגשה, תיקים, כספים ומחירון דיונים. נכנסים עם חשבון Google, והנתונים נשמרים בענן ומסתנכרנים בין הטלפון למחשב.

ההתקנה לוקחת בערך 15 דקות, פעם אחת. **זו מערכת נפרדת לגמרי** מהמלונות ומהקנטינה: פרויקט Firebase חדש ומאגר GitHub חדש.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `config.js` | פרטי החיבור ל-Firebase, ממלאים בשלב 3 |
| `firestore.rules` | כללי האבטחה, מדביקים ב-Firebase בשלב 2 |
| `README.md` | המדריך הזה |

---

## שלב 1: פרויקט Firebase חדש

1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) עם kfirdaabul1@gmail.com.
2. **Create a project**, שם: `yifat-diary`. מבטלים Google Analytics ולוחצים **Create**.
3. **Build ← Authentication ← Get started**.
4. בלשונית **Sign-in method** בוחרים **Google**, **Enable**, בוחרים מייל תמיכה ו-**Save**.
5. שוב **Add new provider** ← **Email/Password** ← מפעילים רק את המתג הראשון (**Email/Password**, לא Email link) ← **Save**. ככה אפשר להיכנס גם עם מייל עבודה וסיסמה.

## שלב 2: מסד הנתונים וכללי האבטחה

1. **Build ← Firestore Database ← Create database**.
2. מיקום: **eur3 (europe-west)**. מצב: **Start in production mode**. **Create**.
3. בלשונית **Rules** מוחקים הכל ומדביקים את כל התוכן של `firestore.rules`.
4. **Publish**.

## שלב 3: מחברים את האפליקציה

1. גלגל השיניים ליד **Project Overview ← Project settings**.
2. ב-**Your apps** לוחצים על `</>` (Web), נותנים שם ו-**Register app**.
3. מעתיקים את הערכים מ-`firebaseConfig` לקובץ `config.js`.
4. שומרים.

> הערכים האלה לא סודיים. מה שמגן על הנתונים זה כללי האבטחה משלב 2.

## שלב 4: מעלים לאוויר (GitHub Pages, בחינם)

1. ב-[github.com](https://github.com): **New repository**, שם: `yifat-diary`, **Public**, **Create repository**.
2. **uploading an existing file**, גוררים את ארבעת הקבצים, **Commit changes**.
3. **Settings ← Pages**: Source **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, **Save**.
4. אחרי דקה-שתיים מופיעה הכתובת, למשל `https://USERNAME.github.io/yifat-diary/`.

> המאגר ציבורי, אבל זה רק הקוד. הנתונים של יפעת (תיקים, לקוחות, כספים) יושבים ב-Firebase ומוגנים בכללי האבטחה.

## שלב 5: מאשרים את הכתובת ב-Firebase

1. **Authentication ← Settings ← Authorized domains ← Add domain**.
2. מוסיפים `USERNAME.github.io` (בלי `https://` ובלי `/yifat-diary`).

## שלב 6: כניסה ראשונה ונתינת גישה ליפעת

1. פותחים את הכתובת ונכנסים עם Google (kfirdaabul1@gmail.com). אתה בעל המערכת.
2. בתפריט (שלושת הקווים) ← **הגדרות**:
   - **מי יכול להיכנס**: מוסיפים את המייל של יפעת (חשבון Google שלה) ולוחצים **הוספה**.
   - **נסיעות**: מאיפה היא יוצאת בבוקר וכמה זמן לחניה ולבידוק.
   - **מחירון דיונים**: מעדכנים את המחירים האמיתיים ולוחצים **שמירת ההגדרות**.
3. שולחים את הכתובת. מי שיש לו Gmail נכנס עם Google. מי שיש לו מייל עבודה (למשל @gsd-law.co.il) לוחץ **פעם ראשונה? יצירת סיסמה**, בוחר סיסמה ומאשר את הקישור שמגיע למייל.

## להוסיף לה את היומן למסך הבית

- **אייפון (Safari):** פותחים את הכתובת ← כפתור השיתוף ← **הוספה למסך הבית**.
- **אנדרואיד (Chrome):** פותחים את הכתובת ← שלוש הנקודות ← **הוספה למסך הבית**.

ככה זה נפתח כמו אפליקציה, בלי שורת כתובת.

## עדכון גרסה

כשיש גרסה חדשה של `index.html`: ב-GitHub נכנסים למאגר ← **Add file ← Upload files** ← גוררים את הקובץ החדש ← **Commit changes**. אחרי דקה הכתובת מתעדכנת. את `config.js` לא מחליפים.
